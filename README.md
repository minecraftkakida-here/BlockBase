# BlockBase

A free, responsive Minecraft fan-hub starter website.

## Run it
Open `index.html` in a browser. No installation or paid service is required.

## Publish it for free
You can upload this folder to a static hosting provider that offers a free tier (for example, GitHub Pages or Netlify). Check the provider's current terms and limits before publishing.

## Before publishing
- Replace the clearly marked example server listings with real, verified server information and permission to list it.
- Review crafting details for the Minecraft edition/version you want to cover.
- Add your own contact/about information and check all content.
- This is an unofficial fan project and is not affiliated with Mojang or Microsoft.

## Current features
- Responsive dark gaming layout
- Guide cards with live search
- Starter crafting corner
- Example server directory
- Interactive one-question quiz

This is a static website. It does not yet include AI automation, user accounts, live server status, or ad monetization.
